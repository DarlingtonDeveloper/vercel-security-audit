# Bundled Geist fonts

These unmodified WOFF2 files come from the public Geist font project, pinned to the commit in SOURCES.json. That manifest records upstream paths, sizes and SHA-256 hashes.

Geist and Geist Mono are distributed under the SIL Open Font License 1.1. The upstream OFL.txt and LICENSE.txt are included verbatim with their original copyright notices. Preserve both files when redistributing the fonts. The renderer embeds the font bytes and the licence text into each HTML report, so opening the report requires no font download.
